# FIIs Analyzer

Aplicação web desenvolvida em **C# com ASP.NET Core Razor Pages** para análise e gerenciamento de Fundos Imobiliários (FIIs), utilizando **Entity Framework Core** e **SQLite** como banco de dados.

O projeto foi criado com foco em organização de carteira, análise de dados e estudo de desenvolvimento web com .NET.

---

## Tecnologias utilizadas

- C#
- ASP.NET Core
- Razor Pages
- Entity Framework Core
- SQLite

---

## Funcionalidades

- Cadastro e gerenciamento de FIIs
- Persistência de dados com SQLite
- Estrutura web com Razor Pages
- Organização e consulta de informações da carteira
- Base para futuras análises e relatórios

---

## Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de:

- Desenvolvimento web com ASP.NET Core
- Estruturação de aplicações com Razor Pages
- Persistência de dados com Entity Framework Core
- Utilização de banco de dados SQLite
- Organização e análise de carteira de Fundos Imobiliários

---

## Estrutura do projeto

- `Program.cs` — configuração principal da aplicação
- `Data/` — contexto e acesso a dados
- `Pages/` — páginas Razor da aplicação
- `appsettings.json` — configurações da aplicação
- `wwwroot/` — arquivos estáticos
